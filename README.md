# Math Master

Mobile-first mental-math speed drill. 80 addition and subtraction questions in 1, 2 or 3 minutes,
growing from single digits to three digits. Optional accounts, synced records and a leaderboard.

Single static file, no build step. Deploy on Vercel with Framework Preset "Other", build command and output directory empty.

Question table (80 questions): Q1-3 3 rows of 1 digit, Q4-10 4 rows of 1 digit, Q11-13 2 rows (2 digits, 1 digit),
Q14-18 3 rows (2, 1, 2 digits), Q19-23 4 rows of 1 digit, Q24-30 4 rows of mixed 1-2 digits, Q31-33 5 rows of 1 digit,
Q34-40 5 rows (about 70% 1-digit then 30% 2-digit), Q41-50 5 rows (3, 2, 1, 1, 1 digits), Q51-80 5 rows of mixed 1-3 digits.
